# Fatima Ramzan — Portfolio

Premium personal portfolio built with Next.js 16, TypeScript and Tailwind CSS v4.

## Getting Started

```bash
npm install 
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — run ESLint

## Customize

Update personal data in `constants/index.ts` (name, links, projects, experience, etc.).

Design tokens live in `lib/theme.ts` and `styles/tokens.css`.

Replace `public/assets/Fatima-Ramzan-Resume.txt` with your real PDF resume and update `resumeUrl` in constants.
